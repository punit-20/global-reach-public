Setup & Permissions

Installation Guide

Follow these steps to add Global Reach (Application ID: 722756633499009045) to your Discord server and verify channel permissions.

1. Prerequisites

  • A Discord account with Manage Server (MANAGE_GUILD) or Administrator permissions on the target server.
  • Two-Factor Authentication (2FA) enabled on your Discord account if your server enforces moderator 2FA.

2. Invite Global Reach via OAuth2

Click the official installation button below to launch Discord's authorization dialog:

Authorize Global Reach on Discord

3. Required Permissions & Least-Privilege Scopes

Scope / Permission Purpose in Global Reach
bot & applications.commands Authorizes the official Discord bot user and reserves slash-command registration scope for planned interactive commands.
View Channels (1024) Required to verify target announcement channel visibility and evaluate channel permission overrides.
Send Messages (2048) Required to post administrator-approved announcements in designated server text or announcement channels.
Embed Links (16384) Required to render structured announcement embeds with clear sponsor attribution.
Read Message History (65536) Included in the default OAuth2 install integer (274877910016) for standard channel compatibility; Global Reach never reads or stores user chat messages.

4. Privileged Gateway Intents & Least Privilege

Global Reach uses standard unprivileged Discord Bot permissions for identity and server metadata verification. The privileged Server Members Intent (GUILD_MEMBERS) is required only when verifying that current holders of an opt-in notification role have active individual consent records prior to announcement dispatch.

5. Pre-Verification Status & Troubleshooting

Global Reach is currently in pre-verification preview: authorizing the application via OAuth2 adds the bot to your server, while live hosted interactive slash commands (/campaign) and in-Discord opt-in buttons are scheduled for post-verification deployment. If channel verification fails with a permission error, ensure channel overrides do not deny View Channels or Send Messages for the bot. Visit the Support Center for additional guidance.
