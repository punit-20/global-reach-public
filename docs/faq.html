Frequently Asked Questions

Click any question below to expand the answer.

Is Global Reach currently live and verified on Discord?

Global Reach (Application ID: 722756633499009045) is currently in pre-verification preview. Core compliance, consent verification, administrator approval, and data-deletion capabilities are implemented and tested offline, while hosted cloud webhook listeners, in-Discord opt-in buttons, and interactive /campaign slash commands are not yet deployed.

Does assigning a Discord role by an administrator count as user consent?

No. Administrator-assigned roles alone are never accepted as proof of individual user consent. Every recipient in an announcement audience must have an active, unrevoked consent record created from a verified user-initiated Discord interaction for that server and role. If any non-bot member holding the target notification role lacks verified individual consent (or has opted out), campaign delivery is blocked.

Does Global Reach exclude other bots from audience checks?

Yes. Global Reach checks Discord's bot account indicator on both interactive events and server member records, automatically excluding automated bot accounts from consent registries and audience lists.

Does Global Reach store the contents of chat messages?

No. Global Reach does not read, monitor, or store user chat message bodies, file attachments, or voice activity.

What does user data deletion erase, and how are privacy requests handled?

When a user deletion action is executed by the operator, Global Reach records a permanent global opt-out, revokes any pending campaign approvals associated with that user ID, and removes the user ID from temporary audience snapshots (it does not alter historical campaign delivery audit entries, external backups, or messages already posted in Discord channels). Because Global Reach is currently in pre-launch preview, a dedicated monitored private privacy intake channel is pending pre-launch provisioning — never post your personal Discord User ID or Server ID in public GitHub Issues or Discussions (see Section 7 of our Privacy Policy).

Is unsolicited mass messaging (spam) allowed with Global Reach?

No. Unsolicited bulk direct messaging, user-account self-botting, spam, and harassment strictly violate both our Terms of Service and Discord's Community Guidelines.
